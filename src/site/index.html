FROM DOWNLOAD TO FIRST CHECKPOINT

Get into your flow.

A guided setup inside the app takes care of the starting point. Here’s the whole journey.

  1. 01

    Install the Windows preview.

    Download the Windows installer below. Install Git for Windows if needed. JavaScript’s runtime comes with the app; install Python only for Python lessons.

  2. 02

    Choose your learning folder.

    Open the app and follow setup. Use a parent folder such as Desktop / My Learning. OutClass creates history and practice folders inside it and organizes each course automatically.

  3. 03

    Add AI help, if you want it.

    Choose a personal OpenAI key or an installed local model in setup or settings. Included AI is awaiting account activation. Local coding, notebooks and checkpoints work without a key.

  4. 04

    Connect the browser extension.

    Until the Chrome store listing is published, use the included extension folder from setup. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select that folder. Enter the app’s connection code in the extension.

  5. 05

    Open a lesson. Make something.

    Visit a Udemy course. In OutClass, choose the course, start a lesson, and choose one project for the whole course. Open Code & learn, edit files, run your code, and keep notes. Your existing coding folder works too. Continue building restores your place when you return.

  6. 06

    Ask, check, and save.

    For course-specific answers, open Udemy’s transcript panel and choose Import visible transcript in the extension. You can also add permitted text in Sources. When a run fails, ask for a hint using its recorded output. Review a checkpoint when you’re done, then save locally. GitHub sync is optional in settings.

  7. 07

    Step away from the example.

    Open Learn by doing for a practical brief, write the solution, run its checks, and explain your approach. Revisit it in Reviews. The Project console can run tests or a development server; React projects need Node/npm installed.

  8. 08

    Try a real contribution.

    Live work finds public issues in your stack and explains what matches your recorded practice. Read the contributor rules, choose a brief, and explicitly clone a separate workspace. The assistant guides your investigation and review. You make the changes and decide when to submit the local PR draft.

A FEW THINGS TO KNOW

Before you start.

Do I need a GitHub repository?

No. OutClass creates local Git history when you choose your learning folder. Later, you can connect one private repository for all your courses. GitHub account connection uses GitHub CLI; setup explains what to install.

Can I keep using VS Code?

Yes. Choose an existing local coding folder when you start a lesson, or use OutClass’s built-in editor. You’re working with ordinary files on your computer. Install the OutClass editor companion from Editors & extensions to bring OffCourse and recorded Quick Runs into VS Code or VSCodium, while keeping your usual editor extensions and debugger.

Does the assistant know the whole course automatically?

No. Course answers use transcripts and material you explicitly import. The extension imports the transcript currently visible on the lesson page. If a source is missing, OutClass tells you rather than claiming to know the lecture.

What can I run inside OutClass?

JavaScript and erasable TypeScript scripts come ready to run. Python uses your installed interpreter or project environment; install compatible libraries through requirements.txt. C/C++ need GCC/G++ or Clang on PATH. React, Next.js and full Node/TypeScript projects use Project console with installed Node.js/npm. Short saved-file runs are limited to 10 seconds. The full desktop terminal supports interactive programs, package installation and long training jobs with your computer's normal permissions. Closing OutClass stops its terminal sessions. A single HTML file can also be previewed.

What leaves my computer?

Your files, notes, library, and history live locally. When you enable and use AI, selected context goes to your chosen connection. Your Architect notebook has separate project memory and explicit sharing controls. GitHub receives reviewed checkpoints only when you connect a repository and sync. OutClass does not run a hosted workspace or collect analytics. Read the privacy details.

Is this the final public release?

This is a Windows preview. The installer is currently unsigned, so Windows may show a publisher warning. The OutClass extension is submitted for Chrome Web Store review. OutClass is independent of Udemy and is not affiliated with or endorsed by Udemy, Linear, or Anthropic.
