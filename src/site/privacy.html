PRIVACY / UPDATED 10 OCTOBER 2026

Your learning stays yours.

GitLearn is a local Windows learning workspace with a Chrome extension for Udemy. It does not require a GitLearn account, run a hosted coding workspace, sell personal information, or collect product analytics.

Browser extension

On Udemy course pages, the extension reads course title, course URL, lecture titles, sections, the current lesson, and visible completion indicators. It sends that context only to your paired local GitLearn companion at 127.0.0.1:47831. Pending course updates and the pairing token are stored in Chrome extension storage. The extension does not read other sites, passwords, general browser history, cookies, or your Udemy account credentials.

When you choose Import visible transcript, the extension reads text in the lesson’s visible transcript panel and sends it to your local course library. It does not automatically import transcripts or download course videos. Only import material you have permission to use.

The extension's data disclosures cover local pairing authentication, Udemy course-page URLs, current lesson and completion context, and explicitly imported website text. They do not include access to your Udemy login or tracking outside course pages. Removing the extension removes its Chrome-local storage; your companion's learning records remain on your computer.

Limited use

GitLearn's use of information received through Chrome extension APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data supports the disclosed learning and pairing features only. It is not sold, used for advertising or lending, or transferred for unrelated purposes. GitLearn provides no developer service that collects or reads your course content. Optional OpenAI and GitHub processing in the companion is described below and controlled by the features you choose to use.

Local files and saved state

Course data, session notes, imported text, search indexes, embedding vectors, chat history, course project bindings, resume positions, and bounded local run evidence, practical task attempts and saved source snapshots, reflections, review schedules, project command records, and contribution briefs are stored in GitLearn’s SQLite database. Your working code and reviewed checkpoints live in the learning folders you choose. You can remove imported sources in the app. Your course folders and app data are retained when you uninstall so your learning is not discarded; you can delete them yourself after exporting anything you need.

OpenAI

AI is optional. The desktop app stores your OpenAI API key using Windows encryption, outside course folders. The source-development companion can read its own local .env instead. Keys are never shipped in downloads, sent to GitHub, or passed to the extension.

When enabled, code help can send your question, selected code, relevant local code or notes, and bounded chat context to OpenAI. Course mode sends your question and relevant imported course passages. When you explicitly attach a recorded run or choose error help, its saved entry-file source and bounded output are included. During a practical task, Code help also includes its brief, checks, reflection, and recorded help use. During contribution work it includes the selected public issue, contributor instructions, your notes, and bounded recorded command results. Personal learning search across courses is a local, explicit search; it does not automatically add other courses to chat. Semantic indexing sends uncached source passages for embeddings when you explicitly refresh the index; question retrieval may send the question for an embedding. AI commit messages use a small scanned diff when separately enabled. The app scans sources for recognizable secrets before indexing or sending them. This does not replace reviewing your own content.

GitLearn requests no response storage when using the OpenAI Responses API. OpenAI’s processing and retention are governed by its own terms and your account settings. API charges are billed to your OpenAI account. See OpenAI’s data controls.

GitHub

GitHub is optional. GitLearn uses Git and GitHub CLI to connect your account and a repository you choose. Reviewed code and notes are uploaded only when you configure a remote and sync. Repository access and uploaded contents are governed by your GitHub account and repository permissions. Live work makes read-only GitHub requests for public issue, repository, contributor-guide, and discussion data. These requests reveal your selected language or repository and ordinary connection information to GitHub. Choosing a brief creates a local record; cloning creates a separate local branch and folder. GitLearn prepares a local pull request draft and does not publish comments, forks, or pull requests for you.

Public website and downloads

This static page includes no analytics, advertising, contact form, or connection to your local workspace. Fonts and images are served with the site. The hosting and download providers may process ordinary connection information such as IP addresses under their own policies. External resource links open the relevant provider’s website.

Questions and changes

For privacy questions, open an issue in the GitLearn repository without including API keys, personal course transcripts, or private code. Changes to data handling will be reflected here before a release that introduces them.
