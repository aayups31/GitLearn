# OutClass 0.7.2 · Minimal workspace preview

This Windows preview gives the editor the main working surface. It is a local preview build; the public website and Chrome Web Store listing are separate releases.

- The teacher and lesson guidance open on request. Course direction, assignments, practice and task checks now live in the Lesson panel, with a quiet signal when a practice opportunity is ready.
- Output, Terminal, Project and Notes share one bottom strip. Only the selected tool occupies editor space. Previous output stays available without opening on launch.
- Focus editor hides navigation, files, the teacher, lesson heading and bottom panels. Exit restores the previous layout. Hidden panels retain unfinished work and running terminal sessions.
- A shorter sidebar keeps the everyday learning destinations visible. More tools contains practice, live work, ideas, checkpoints, editor integrations, Academy, Creator Studio and GTM.
- Resizable panels, mobile full-width views, local save/run, source citations, assignments, hints, stale-code checks, reflections and checkpoints remain available.

This build also packages the existing Academy, Creator Studio and GTM work from main. Connecting social accounts still requires the relevant developer credentials and account permissions; installing the app does not connect or publish to those accounts.

The Windows preview is unsigned. The native terminal runs with the user's normal permissions. Standard VS Code extensions continue to run in an external compatible editor through the companion, rather than inside OutClass.

See [workspace controls](../workspace-layout.md) for the new layout.
