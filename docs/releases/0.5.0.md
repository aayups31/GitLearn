# OutClass 0.5.0 · Active learning preview

This Windows/Udemy preview adds personal learning directions, changed-requirement practice, an independent-project milestone path, evidence-backed learning ledgers, enforced code/run/hint freshness, checkpoint video links, change-impact review, observed regression alerts, and bounded interactive script input. Existing course files, checkpoints, pairing, settings and private GitHub workflow remain compatible.

## Use the new flow

1. Install the updated app. Existing users retain their local learning folders and history.
2. Install the 0.5.0 extension ZIP with **Load unpacked**. The Chrome store item remains on the earlier pending-review package; the ZIP contains this release's timestamp support.
3. In **Learn by doing → My direction**, choose the outcome, experience and session budget.
4. Use a course project, save its brief, and attach real recorded work to concrete milestones.
5. Complete a practice task, then choose **Try the changed requirement** for a fresh attempt.
6. Save and test code before asking for another hint. Edited files or outdated run attachments produce **Test your changes first**.
7. A short local run can accept one line at a time within its ten-second limit. Use Project console for longer explicit commands.
8. Review change impact and actual regression alerts when earlier behavior fails; make and test the fix yourself.
9. Saved checkpoints with a fresh observed Udemy position expose **Sync to video**. The extension opens the lecture position, pauses the player, and never starts playback automatically.
10. Export the HTML or Markdown Learning Ledger from **My direction**. Review it before sharing.

## Scope and evidence

Ten curated JS/Python tasks: six original practice/project briefs plus four changed-requirement challenges. Six project milestones. Project progress and explanations remain learner-reported with attached local evidence. A passing run or named check is not a certification of broad mastery. AI is optional, cannot edit/run code, and uses the learner's own key. Coding agents remain deferred.

Video anchors use the latest visible-player observation (normally within three seconds), with a fifteen-second freshness limit. An updated extension, a loaded player and legitimate access to the course are required. Import/dependency matching is a bounded heuristic; regression alerts report earlier success versus a later failure and do not prove a causal edit. Local runtime limits do not constitute OS isolation.

Ledgers include exact checkpoint reflections, project/file structure, Git references, task checks, bounded source excerpts, hashes and recorded help. Records are locally editable, not unforgeable credentials. HTML is escaped and exports are scanned for configured secrets. Outside assistance and authorship are not measured.
