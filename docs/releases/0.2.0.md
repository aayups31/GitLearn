GitLearn is now a Windows learning workspace with guided setup, a real local code editor, Udemy course context, sourced AI help, and reviewed Git checkpoints. The website is a separate static landing page ready for Vercel.

Download GitLearn-Setup-0.2.0.exe, install it, and follow first-run setup. Choose a parent learning folder; GitLearn organizes each course inside it. Git for Windows is required for checkpoints. JavaScript's runtime is bundled; Python lessons need a local Python installation. VS Code and GitHub are optional.

The Chrome Web Store listing is pending. The app includes an unpacked extension folder accessible from setup; the separate GitLearn-Chrome-0.2.0.zip is also available. In Chrome, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extracted folder. Enter the connection code from GitLearn. Open a Udemy course, then start the lesson in the app.

For course answers, explicitly import a visible transcript from the extension or add permitted text in Sources. AI requires your own OpenAI API key, stored using Windows encryption. No developer API key is included in any download. Local editing and checkpoints work without AI.
