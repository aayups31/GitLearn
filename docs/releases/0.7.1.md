# OutClass 0.7.1 · Connected learning preview

The course, practice task, local execution and OffCourse conversation now form one continuous workspace flow.

- Start a suggested task directly in the editor. Keep your learning goal visible, open the correct task file, run real checks, save a reflection, and start a changed requirement without leaving the workspace. The project-path action opens your personal direction directly.
- OffCourse uses the same teaching policy for personal, local and included AI. Actual attempts select conceptual guidance, a diagnostic experiment, a narrow inspection or a transfer question. Recorded command errors are included in the teacher's context. Hint mode blocks fenced code, and explanations reject obvious replacement snippets using the learner's declared names. These are conservative guards, not a semantic guarantee that every possible solution will be detected. A rejected replacement still teaches from the actual failed check or recorded error.
- The teacher controls wait for local checks to finish. Quick Run and project commands save all open file drafts first. Existing conflict protection preserves edits made by an external editor.
- Completed-task details prioritize reflection and transfer. Additional suggestions stay quiet while that task is being reviewed. Recorded checks remain inspectable and program output can collapse to keep useful space for coding; passing checks is not a claim of mastery.
- AI setup distinguishes unsaved choices, a saved connection and enabled guides. Passwordless sign-in enables the guides with explicit consent, supports retrying a code and changing email, and reports allowance outages separately from account status. A connection check reads model/account metadata without generating a paid answer.
- Account refresh and encrypted-vault writes cannot restore a session after sign-out. Network/model failures provide a recovery action and retain matching local sources. Malformed hosted model output refunds the learner and is reported as a service failure.

## Setup and boundaries

The preview runs on Windows x64. Its native terminal uses your normal computer permissions; the installer is unsigned. The built-in editor remains the OutClass editor. Standard VS Code extensions run in VS Code/VSCodium through the companion VSIX, not inside OutClass.

Personal-key and installed local-model connections are available. Included AI is implemented and tested against a local service fixture without a learner provider key. Public Supabase email, PostgreSQL usage and Stripe subscriptions still require the owner's infrastructure connection and a real staging check before activation. See [deployment steps](../../services/ai/README.md).

Udemy context comes from the browser companion and explicitly imported material. Live authenticated Udemy layouts and actual learning outcomes require learner trials; synthetic fixtures and model checks do not establish those results.
