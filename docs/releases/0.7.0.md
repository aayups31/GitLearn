# OutClass 0.7 — a workspace for learning and making

## Included in this Windows preview

- **OffCourse** is the course-aware teacher. Each course keeps separate retrieval, conversations, attempts, project milestones and contribution guidance. Progressive hints and the existing stale-code guard remain in place. Neither guide edits or executes learner code.
- **The Architect** has project-specific conversations, a problem statement, linked courses and a notebook for ideas, decisions and reflections. Reviews connect dated notes and linked learning goals to an achievable experiment. Original learner notes and AI interpretations are visibly distinct. A useful local planning checklist works without AI.
- **Idea capture** is an optional launch prompt. Automatic notes are opt-in, deduplicated saved checkpoint reflections from linked courses. Reviews are offered after three days; they do not trigger paid calls automatically. Edit/delete entries and remove projects. These changes clear derived project conversations and associated teacher memory. Deleting imported automatic notes prevents recapture.
- **Shared context** requires a project sharing setting and an explicit project selection in an OffCourse question. Changing context during inference invalidates the answer. Other courses/projects are not silently merged into conversations.
- **Flexible layout**: drag or use arrow keys on course, file, teacher and terminal dividers; hide courses/files/teacher; move the teacher left or right; maximize/collapse the terminal; retain the layout and reset it. Mobile views remain usable.
- **Integrated terminal**: real local PowerShell in the desktop application, project cwd validation, interactive stdin, six persistent shell sessions, resizing and long-running programs. Closing a terminal stops its shell; closing OutClass stops its terminal sessions. Initial use explains normal user permissions. OutClass credentials are excluded from its environment. Display history is bounded and shell output does not become verified test evidence automatically. Quick Run/Project Console remain available.
- **AI connections**: personal OpenAI keys, a user-installed OpenAI-compatible localhost model, or a configured included-AI service. Local keyword RAG remains available in every mode. Included/local mode never silently uses a personal key for embeddings. Included-AI Windows account sessions are encrypted, and allowance/sign-in errors are actionable.
- **VS Code / Code OSS bridge**: an installable OutClass VSIX with SecretStorage pairing, workspace trust, explicit course scope and progressive code hints. Open the same course folder, use your editor's extensions/debugger/terminal and the Udemy browser extension. OutClass detects standard VS Code/VSCodium installations, installs the companion on request, lists installed extensions and revokes pairings. Portable editor users can install the VSIX manually.

## Use it

1. Install the new Windows preview and choose or retain your learning folder.
2. In **Settings**, choose your AI connection and enable the guides. A personal key is optional for local learning features and the notebook; a local model must already be installed/running on this computer.
3. Connect the Udemy Chrome extension as before, then start or continue a course.
4. In **Code & learn**, drag dividers and open **Terminal**. Enable the full local shell only when you want ordinary terminal permissions. Install compatible packages, run training or start servers through it.
5. Open **Ideas & architecture**, capture a project and link relevant courses. Add a problem statement, original notes and architecture decisions; ask the Architect or request an idea review. Toggle launch prompts and automatic reflection notes here.
6. To attach this notebook to the teacher, enable its sharing setting and select it in OffCourse's Code help composer.
7. For an external editor, open **Editors & extensions**, install the OutClass companion, open the current course's exact folder and generate an editor code. Run **OutClass: Connect course workspace** in the editor, enter the code, then save/test your attempt and ask OffCourse.

## Hosted AI is prepared, not publicly activated

As requested, Supabase authentication/database and Stripe subscription integration are prepared for accounts to be connected later. The service keeps provider secrets server-side, verifies account tokens, supports email OTP and encrypted desktop sessions, atomically reserves per-user monthly allowances, imposes a global monthly attempt limit and request/concurrency bounds, refunds failed answers to the learner, and processes verified subscription webhooks. A global attempt remains counted after provider failure so repeated failing calls cannot evade the owner limit. Pricing and actual accounts are not configured. Follow [the service deployment guide](../../services/ai/README.md) and validate real infrastructure in staging before offering public subscriptions.

## Exact boundaries

This is not a full Code OSS fork. VS Code-compatible extensions run in VS Code or VSCodium through the bridge, not inside OutClass's built-in CodeMirror editor. Microsoft's marketplace is not promised for an OutClass fork. WSL/SSH/remote extension hosts are unsupported. One course session is active at a time; each course retains its own history and course project, and terminal tabs name their associated course.

Terminal use has normal computer privileges. Quick Run's bounds are not a sandbox for the full terminal. Unsigned Windows preview; no signing certificate is configured. Chrome ZIP and editor VSIX are downloadable previews, not claims of public store approval.
