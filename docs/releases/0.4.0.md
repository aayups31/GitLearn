Superseded by [GitLearn 0.4.1](https://github.com/aayups31/GitLearn/releases/tag/v0.4.1), which fixes installed Windows project tools launched through PowerShell. Use the 0.4.1 downloads for React/npm projects.

GitLearn 0.4 helps you start practical work during a course and carry it into a real contribution workspace.

- Suggestions appear after recorded successful runs or checkpoints, recognize section transitions, and explain why the moment fits. Defer them whenever you want.
- Learn by doing includes six curated JavaScript/Python task and small-project briefs, progressive hints, saved-code behavior checks, reflections, and recorded help use. You implement the work.
- Fresh-file reviews use a 1/3/7/14-day schedule. Search recorded learning across courses explicitly and export your local learning record.
- The Project console runs explicit commands, tests, line-input programs, and development servers. Create separate React/Vite or Python starters without replacing your course files.
- Live work checks public GitHub issues, contributor guides, and repository state. Inspect explainable matches, select a local brief, clone a separate contribution folder and branch, and work through baseline/reproduction/change/review steps with teacher guidance. Recorded commands and a diff against the starting revision support a local PR draft. GitLearn does not publish for you.

Download GitLearn-Setup-0.4.0.exe. Save work and close an older GitLearn version before updating. Existing learning files and local history are retained. Git is required for checkpoints; JavaScript scripts are bundled; Python needs a local interpreter. React projects require installed Node/npm. VS Code and GitHub backup are optional. AI uses your own OpenAI API key; no developer key is included.

Until store approval, use the extension folder included in desktop setup or GitLearn-Chrome-0.4.0.zip with Chrome's Load unpacked action, then enter the app's connection code. Course answers use transcripts/resources you explicitly import.

This is an unsigned Windows x64 preview. Checks verify the curated task's saved entry file and bounded behavior cases; they are not a tamper-proof grading sandbox or evidence of industry readiness. Reviews repeat the curated brief. The project console is not a full PTY, debugger, or language server. Learner goals, validated generated transfer tasks, richer project rubrics, additional platforms/OS support, and coding-agent integration remain on the roadmap; coding agents remain deferred. GitLearn is independent of Udemy, Linear, and Anthropic.
