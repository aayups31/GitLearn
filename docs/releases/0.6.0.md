# OutClass 0.6.0 · More languages, real project environments

This Windows/Udemy preview adds React, React with TypeScript, Next.js App Router with TypeScript, Node.js, standalone TypeScript, Python package profiles, C and C++ project starters. Each creates a separate folder without replacing your code, with explicit prepare, install, check/build and start commands in Project console. Dependencies are installed only when you run the reviewed command.

## Start here

1. Install the updated Windows app. Existing course folders, history and pairing remain compatible.
2. Open a course in **Code & learn → Project console**, choose a technology and select **Create project**.
3. Choose **Prepare environment**, review the command and run it. Python projects then use **Install packages**. Web projects require an installed Node.js/npm toolchain.
4. Choose **Check/build project** and **Start project** as needed. React/Next.js use a loopback dev server; **Open local app** uses the provided port (5173/3000).
5. Single saved JavaScript, erasable TypeScript, Python, C and C++ files can use **Run**. C/C++ compile with GCC/G++ or Clang on PATH before execution. Compiler output, actual exit status, interactive input, ten-second execution bounds, run history, stale-code guards and regression evidence are retained.
6. Use **Learn by doing** to select the course's language or another language explicitly. TypeScript adds typed versions of existing briefs; C/C++ add numeric-boundary and non-finite-input transfer tasks. There are nineteen curated tasks in total, including eight changed-requirement challenges.

## Python packages

Choose an empty requirements file or NumPy/pandas, FastAPI, Flask, scikit-learn or PyTorch. Edit requirements.txt to use other compatible libraries. Prepare a project `.venv`, then install requirements; saved-file runs and generated Python commands select the nearest project environment. Packages are not bundled. GPU/native dependencies and Python/OS compatibility still apply. Pin dependency versions after verifying your course's environment.

## Clear limits

Run saved file strips erasable TypeScript types; it does not type-check. The standalone TypeScript project's Start command uses tsx (including enum transformation); Check/build project uses tsc. React/Next.js JSX/TSX use their dev server. Decorators and aliases require your course's configuration. Component behavior is not automatically assessed by the foundational function exercises. Import your course references for sourced AI help; OutClass does not include every library's documentation.

Short C/C++ runs compile one entry with local headers. CMake/Project console handles your explicit multi-file workflow. MSVC requires its developer environment and possibly a different generator/executable path. Runtime limits are not an OS sandbox. A bounded line-input console is not a full PTY/debugger or language server. Coding agents remain deferred.

The existing Chrome store submission remains the earlier 0.4.2 package pending review. Use this preview ZIP with Load unpacked for the current extension; no new store approval is claimed.
