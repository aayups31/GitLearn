# OutClass 0.4.2 Windows preview

GitLearn is now OutClass. Break free from tutorial hell. OutClass the lesson.

- The homepage explains the gap between following a lesson and building independently, with a blue breakout visual and locally served GSAP scroll animations. The practical-learning journey covers course context, practice before the course ends, evolving projects, and guided contributions.
- OutClass branding appears throughout the Windows app, setup, browser extension, and privacy page. Existing learning data, encrypted-key location, pairing protocol, Git history, and repository URLs stay compatible. No learning folders are moved.
- Phone layouts, keyboard navigation, live reduced-motion changes, and unavailable animation scripts retain usable content and downloads. The product demonstration is labeled as illustrative example content.

Install the Windows x64 preview, then follow setup. Git is required for checkpoints. Single-file JavaScript is bundled; Python needs a local installation. AI and GitHub are optional.

The installer is unsigned. The previously submitted GitLearn 0.4.1 Chrome item remains pending Google's review. Load the included OutClass extension unpacked for this preview; this release does not create a second store item or imply store approval. The learning functionality retains the six curated JavaScript/Python practice briefs and guided public-issue workflow from 0.4.1. Broader platform and curriculum support remains on the roadmap.
