GitLearn 0.4.1 includes the practical-learning and contribution workflow from 0.4.0 and fixes Windows project commands launched through PowerShell. Installed Node/npm tools now receive the Windows executable and command-shell system settings they need. Companion API keys and account tokens remain excluded from project processes.

The public landing page is live at https://git-learn-black.vercel.app/, with product information, the complete setup guide, privacy, and release downloads. Main pushes deploy through the connected Vercel project.

Download GitLearn-Setup-0.4.1.exe. Save work and close an older GitLearn version before updating. Existing learning files and local history are retained. React projects require installed Node/npm; the bundled JavaScript runner works without it. Python requires a local interpreter. AI is optional and uses your own OpenAI API key.

Until Chrome store approval, use the extension folder included in desktop setup or GitLearn-Chrome-0.4.1.zip with Chrome's Load unpacked action, then enter the app's connection code. Course answers use transcripts/resources you explicitly import.

This is an unsigned Windows x64 preview. Practical-learning briefs currently cover six curated JavaScript/Python tasks and small projects. Their behavior checks are not a grading sandbox or a certification of industry readiness. The project console supports commands and line input but is not a full PTY, debugger, or language server. Broader platforms, generated transfer tasks, richer project rubrics, and the remaining learning roadmap are still in development. Coding-agent integration remains deferred.
