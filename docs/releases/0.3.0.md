GitLearn 0.3 adds a daily learning loop: continue your own project, understand an actual error, make the next change, and review what you built.

- One evolving project per course, with an automatic folder or an existing local project. Separate lesson folders remain available. Upgrading preserves existing files and checkpoints.
- Continue building restores your lesson, folder, saved file position, and session note. Missing files fall back gracefully; moved folders can be reattached without moving code or changing source Git history.
- Give me a hint and Explain this error use recorded local run evidence. Changed entry files are marked stale. Hint-first tutoring supports reasoning; suggested fixes still need a real rerun.
- Device readiness checks JavaScript, Python, Git, folder access, AI configuration, and extension pairing without revealing credentials.

Download GitLearn-Setup-0.3.0.exe. Save your work and close an older running GitLearn version before opening the update. Follow first-run setup if this is your first installation. Git is required for checkpoints; JavaScript is bundled; Python lessons require a local interpreter. VS Code and GitHub are optional.

The Chrome Web Store listing is pending. Use the included extension folder from setup or GitLearn-Chrome-0.3.0.zip with Chrome's Load unpacked action, then enter the connection code. Course answers use transcripts and resources you explicitly import. Add your own OpenAI API key for AI help; no developer key is included.

This remains an unsigned Windows x64 preview with short JavaScript/Python runs and single-file HTML preview. Interactive terminals, project environments, independent practice tasks, learning reviews, and guided open source contributions are the next roadmap stages. Coding-agent integration remains deferred. GitLearn is independent of Udemy, Linear, and Anthropic.
