# A workspace with room to work

Code & learn opens with the file tree and editor. The assistant, lesson guidance and bottom panels stay closed until requested. A previous run remains available in Output without opening the panel on launch.

- **Lesson** opens course direction, assignments and practical tasks in the side panel. A blue dot signals an available practice opportunity. **Conversation**, **Sources** and **Architect** are tabs in that same panel.
- **OffCourse** opens the teacher. Error actions open it with the recorded run attached. Hint style and additional context are under the composer's expandable controls.
- **Output**, **Terminal**, **Project** and **Notes** share one bottom strip. One panel is visible at a time. Running a file opens Output. Hiding a terminal preserves its running shell; stopping it remains a separate action.
- **Focus editor** hides both sidebars, the file tree, lesson header and bottom panels. Exit restores the previous layout and open panel. Code and assignment drafts remain mounted when their panels are hidden.
- Drag panel dividers, or focus them and use the arrow keys. Sizes and sidebar visibility are remembered. Layout options contains assistant placement and Reset layout.
- The main sidebar keeps Overview, Code & learn and My courses visible. More tools contains practice, live work, ideas, checkpoints, editor connections, Academy, Creator Studio and GTM.

On narrower windows, Code and Assistant switch between full-width views. The mobile navigation keeps the same destinations under More tools.

The layout v2 migration preserves previously resized dimensions while closing secondary panels for the new default. It does not change learning files, checkpoints, notes, account settings or credentials.
